# Contribuidores

Quién ha aportado qué, y cuándo. Orden cronológico.

El registro es público porque la trazabilidad de las contribuciones es parte de lo que este proyecto afirma que se puede construir: si no somos capaces de registrar las nuestras con honestidad, no tenemos derecho a proponérselo a nadie.

Para añadirte: abre un PR editando este archivo, o pídelo en el issue de tu contribución.
