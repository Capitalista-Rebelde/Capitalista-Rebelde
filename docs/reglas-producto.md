# Reglas de producto (no negociables)

1. Nunca mostrar una dirección de contrato no verificada en fuente oficial. Una dirección equivocada son fondos perdidos.
2. Nunca presentar proyecciones como garantías; incluir siempre el escenario adverso.
3. Sin botón de retirar en donaciones irreversibles.
4. Si un dato externo falla, se marca como "no verificado"; nunca se inventa.
5. Español neutro, claro, sin jerga innecesaria.
