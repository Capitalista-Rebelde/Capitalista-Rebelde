# Glosario

- **Curador** — selecciona y evalúa estrategias de terceros; no las opera.
- **Rendimiento donado** — parte del rendimiento cedida de forma irreversible a una misión.
- **Misión** — acción real con objetivo, ejecutor, verificador y evidencia.
- **Ejecutor / Verificador** — depositan fianza y la pierden si actúan de mala fe.
- **Fianza** — garantía económica que alinea incentivos.
- **ADR** — registro de una decisión con su contexto y alternativas descartadas.
